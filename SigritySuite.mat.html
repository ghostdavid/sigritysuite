add_surface_roughness(props: Dict[str, Any]) -> None
 
Register a named conductor surface roughness model in the project material library.
Requires an open project with a valid material manager. If 'Name' or 'Type' is missing or empty, the call returns
without error. Invalid 'Type' or out-of-range numeric values write a message to the output window and return.
 
Parameters
  props: dict - Case-sensitive keys:
    'Name' - str - Required. Unique name for this roughness model in the project.
    'Type' - str - Required. Model identifier. Supported values:
      'Huray' - Huray snowball model; use 'SurfaceRatio' and 'SnowballRadius'.
      'ModifiedHammerstad' - Hammerstad-style model; use 'RoughnessFactor' and 'RMSValue'.
      'ModifiedGroisse' - Groisse-style model; use 'RoughnessFactor' and 'RMSValue'.
      'CausalHuray' - Only accepted when the environment variable MAT_ROUGHNESS_NEWSR is set; use 'SurfaceRatio' and 'SnowballRadius'.
      'CausalHammerstad' - Only accepted when MAT_ROUGHNESS_NEWSR is set; use 'RoughnessFactor' and 'RMSValue'.
 
  Numeric keys (use the pair that matches 'Type'):
    'SurfaceRatio' - float - First Huray parameter; must be greater than or equal to 0 and less than 10.
    'SnowballRadius' - float - Second Huray parameter; must be greater than or equal to 0.
    'RoughnessFactor' - float - First Hammerstad/Groisse parameter; must lie in the closed-open interval [1, 10) enforced by the command.
    'RMSValue' - float - RMS roughness for Hammerstad/Groisse; must be greater than or equal to zero.
 
Returns
  None
 
Example

  srm.add_surface_roughness({'Name': 'RoughHM', 'Type': 'ModifiedHammerstad', 'RoughnessFactor': 2.0, 'RMSValue': 0.5})
